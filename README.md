# Muhammed Afsal — afsify

Personal portfolio of Muhammed Afsal, **Frontend Developer at Bizforz**, focused on React and TypeScript with independent full-stack project experience.

**Production URL:** [www.afsify.com](https://www.afsify.com/)

Open to the right Frontend / Full-Stack role and selected freelance web projects outside employment commitments.

## Application

The Next.js 16 / React 19 / TypeScript application lives in [frontend](frontend). It contains thirteen content routes and eight projects: five independent projects (EkaVio, Codisify Devlearn, Chateph Messenger, Afssian E-Commerce and Taskent Dashboard) and three professional websites (LE’VALOR Hotels & Resorts, Home at Paris and Bizforz Solutions Pvt Ltd). The professional websites were delivered through employment at Bizforz; they are not freelance contracts. EkaVio remains the sole flagship and is explicitly presented as active development / staging.

## Local development

Use Node.js 22 or newer:

```sh
cd frontend
npm ci
npm run dev
```

Open http://localhost:3000. On Windows, use `npm.cmd` if PowerShell blocks `npm.ps1`.

Development deliberately uses `next dev --webpack` to preserve the verified workaround for local Console Ninja/Turbopack instrumentation. Production uses `next build`.
